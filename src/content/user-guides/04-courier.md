# Курьер — руководство

Вы доставляете готовые заказы. Видите **только** заказы на выдаче.

**Меню:** Главная · Заказы · Справка

**Нет:** Новый заказ, Очередь, Задачи, Клиенты, Отчёты, Каталог, Админка.

---

## Ваши ограничения

| Тема | Правило |
|------|---------|
| Видимость | Только **Готов к выдаче**, **У курьера**, **Выдан** |
| Статусы | Готов ↔ У курьера → Выдан |
| Создание / правка заказа | Нет |
| Файлы | Нет |
| Задачи / комментарии | Нет |
| Отчёты | **Никогда** |
| Отмена / удаление | Нет |
| «Для курьера» | **Только чтение** |

---

## Главная

Короткая сводка по заказам выдачи и ссылка в Заказы. KPI денег нет.

---

## Заказы

### Список

Только статусы выдачи. Поиск по номеру. Раскрытие состава — если доступно в списке.

### Карточка — что можно

| Действие | Можно? |
|----------|--------|
| Смотреть номер, клиента, состав, сумму | Да (свои видимые) |
| Читать «Для курьера» | Да |
| Менять статус по цепочке выдачи | Да |
| Править поля / цены | Нет |
| Загружать файлы | Нет |
| Комментарии | Нет |
| Отмена / удаление | Нет |
| ТТН | Нет |

**Пример:** в «Для курьера» указан адрес офиса — везёте туда, статус → «У курьера» → после вручения → «Выдан».

Заказ «На производстве» вы **не увидите**.

## Кейсы

### C1. Забрать
Заказы → «Готов к выдаче» → прочитать «Для курьера» → → «У курьера».

### C2. Выдать
«У курьера» → → «Выдан». Заказ уходит из активной выдачи; SLA останавливается.

### C3. Вернуть на точку выдачи
При необходимости ← обратно на «Готов к выдаче» (если переход разрешён графом).
