# Администратор — полное руководство

## Кто вы

Админ видит и настраивает всю систему: пользователи, каталог цен, SLA, отчёты, любые заказы и статусы.

## Что есть в меню

Главная · Заказы · Новый заказ · Очередь · Задачи · Клиенты · Отчёты · Каталог · Админка

## Ограничения других ролей (сводка)

| Роль | Видит заказы | Создаёт | Правит поля | Статусы | Отмена / удаление | Файлы | Задачи | Отчёты | Каталог / админка |
|------|--------------|---------|-------------|---------|-------------------|-------|--------|--------|-------------------|
| **Фотоцентр** | Только своя точка | Да | Только свои, статус «Новая» | Нет | По умолчанию нет (можно выдать флагами) | Блок «точка»; чужие заказы не видит | Да | Нет никогда | Нет |
| **Производство** | Все | Да | Только заказы `source=production` | До «Готов к выдаче» | Да | Догрузка блока «точка» | Да | Только с флагом | Нет |
| **Дизайнер** | Все | Нет | Нет | До «Готов к выдаче» | Нет никогда | Блок «дизайнер» | Да | Только с флагом | Нет |
| **Курьер** | Только выдача (готов / у курьера / выдан) | Нет | Нет | Только цепочка выдачи | Нет | Нет | Нет | Нет никогда | Нет |

### Важно про флаги прав (Админка → пользователь)

- Можно **выдать** фотоцентру отмену / soft-delete; production/designer — доступ к отчётам или смену цены.
- Можно **снять** (deny) права у производства (например, запретить отмену).
- Дизайнеру **нельзя** дать отмену/удаление — система это игнорирует.
- Фотоцентру и курьеру **нельзя** открыть отчёты флагом.

### Шпаргалка статусов

| Кто | Что делает со статусом |
|-----|------------------------|
| Фотоцентр | Не двигает |
| Производство / дизайнер | ←/→ до «Готов к выдаче» |
| Курьер | Готов ↔ У курьера → Выдан |
| Админ | ←/→ и «Перейти в…» куда угодно |

## Кейсы админа

### Кейс A1. Создать точку сети (фотоцентр)

1. Админка → Пользователи → Новый.
2. Роль: **Фотоцентр**, email, пароль, название точки.
3. Система создаст клиента-точку и привяжет пользователя.
4. Точка войдёт и увидит только свои заказы.

### Кейс A2. Создать внешнего клиента (не точка)

1. Клиенты → новый внешний клиент (или при создании заказа).
2. У него нет логина. Заказы создают производство/админ, выбирая этого клиента.
3. При необходимости админ может **soft-delete** внешнего клиента (не точку сети).

### Кейс A3. Выдать фотоцентру право отмены

1. Пользователи → точка → включить «Отмена заказа».
2. У точки появится кнопка отмены (с причиной). Soft-delete — отдельный флаг + пароль.

### Кейс A4. Запретить производству отмену

1. Пользователь production → снять галку / поставить deny на отмену.
2. Кнопка отмены исчезнет; API тоже откажет.

### Кейс A5. Прыжок статуса «Перейти в…»

1. Открыть заказ.
2. Админ может перевести в любой статус через модал (не только соседний шаг).
3. Остальные роли — только ← / → по правилам.

### Кейс A6. Каталог и цены

1. Каталог → дерево категорий / позиции / цены.
2. Импорт xlsx (базовый формат 1С) или preview.
3. ☑ «Заменить цены» — обновляет только цены совпавших позиций.
4. Уже созданные заказы **не** меняют цену при смене прайса (снимок на заказе).

### Кейс A7. Отчёты за месяц

1. Отчёты → период (по умолчанию текущий месяц).
2. KPI: число заказов, выручка, средний чек, % выданных.
3. Отменённые и soft-deleted **не** в KPI.
4. Экспорт CSV/Excel / печать.

### Кейс A8. Soft-delete заказа

1. На карточке → Удалить.
2. Ввести **свой** пароль + комментарий.
3. Заказ исчезнет из рабочих списков; статус не меняется на «Отменён».
4. Админ может включить «Показать удалённые» в списке.

### Кейс A9. SLA

1. Админка → SLA → цель (по умолчанию 72 ч).
2. Просрочка: уведомления push/Telegram (cron).
3. При отмене / soft-delete / «Выдан» SLA останавливается.

## Частые вопросы

**Почему цена в заказе не обновилась после импорта прайса?**  
Цена копируется в заказ при создании. Старые заказы не пересчитываются.

**Чем «Отменён» отличается от «Удалён»?**  
Отмена — статус с причиной, виден в воронке как отменённый. Удаление — скрытие из списков (нужен пароль); для KPI оба исключены.

**Почему у сотрудника нет пункта «Отчёты»?**  
Нужна роль admin или флаг у production/designer. Фотоцентру и курьеру отчёты недоступны.
