# Дизайнер — руководство

Вы работаете с макетами и статусами в цехе. Видите **все** заказы. Заказы **не создаёте**.

**Меню:** Главная · Заказы · Очередь · Задачи · Клиенты · Справка · Отчёты (только с флагом)

**Нет:** Новый заказ, Каталог, Админка.

---

## Ваши ограничения

| Тема | Правило |
|------|---------|
| Новый заказ | Нет |
| Правка состава / цен / полей заказа | **Нет** |
| Отмена / soft-delete | **Нет никогда** (флаги админа не помогут) |
| Аудит цен | Нет |
| Статусы | ←/→ до «Готов к выдаче» |
| Курьерские статусы | Нет |
| Файлы | Загрузка в блок **дизайнера** |
| Отчёты | Только с флагом |
| Каталог / админка | Нет |

---

## Главная

Оперативная сводка (очередь, SLA, задачи, последние заказы). KPI денег — только при флаге отчётов.

---

## Заказы

### Список

Поиск, фильтры, раскрытие состава. **Нет** ТТН (это production/admin).

### Карточка — что можно

| Действие | Можно? |
|----------|--------|
| Смотреть заказ, состав, статусы | Да |
| Править позиции / цены / клиента | **Нет** |
| ←/→ статусы (до ready) | Да |
| «Перейти в…» | Нет |
| Комментарии + ☑ проблемный макет | Да |
| «Для курьера» | Обычно только чтение |
| Файлы блока дизайнера | Загрузка / скачивание |
| Файлы блока точки | Обычно скачивание |
| Отмена / удаление | **Нет** |
| Аудит | Нет |
| ТТН | Нет |

**Пример:** ошибка в заказе — комментарий производству/админу; сами состав не меняете. Нужна отмена — только они.

---

## Очередь

Основной рабочий экран: ←/→, состав, «макет: есть/нет».

**Пример:** «Принят» → «У дизайнера» → загрузить макет → передать «На производстве».

---

## Задачи

Мои / Поставленные / Все (ваши ∪ поставленные). Статусы задачи: open → in_progress → done.

**Пример:** задача от точки «макет визиток» → in_progress → загрузка файла → done.

---

## Клиенты

Справочник и история заказов (чтение). Удаление клиентов — не ваша зона.

---

## Отчёты (если флаг)

Как у производства: период, KPI, экспорт. Без флага пункта меню нет.

## Кейсы

### D1. Взять в работу
Очередь → → «У дизайнера» → файлы в блок дизайнера.

### D2. Проблемный макет
Комментарий + ☑ — уведомление уйдёт ответственным.

### D3. Нельзя отменить
Кнопки нет; пишете комментарий → production/admin.
