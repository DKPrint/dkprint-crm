# Фотоцентр (точка) — руководство

## Кто вы

Принимаете заказы клиентов на своей точке. Видите **только заказы своей точки**.

## Меню

Главная · Заказы · Новый заказ · Задачи

**Нет:** Очередь, Клиенты (весь справочник), Отчёты, Каталог, Админка.

## Ограничения

- Не видите заказы других точек.
- Не двигаете статусы (←/→ нет).
- Правите заказ **только** пока статус **«Новая»**.
- Цену после создания не меняете (цена каталога берётся с сервера при создании).
- Отмена / удаление — **нет**, пока админ не выдаст флаг.
- Отчёты — **никогда**.
- Файлы: загружаете в блок **клиента/точки**; блок дизайнера — только смотреть/скачивать свои заказы.

---

## Кейсы

### Кейс F1. Новый заказ из каталога

1. Новый заказ.
2. Клиент = ваша точка (автоматически).
3. Категория → подкатегория → позиция → количество.
4. При необходимости ☑ «Ручная позиция» (своё название и цена).
5. Сохранить. Номер вида `DK-260902-1`.
6. Можно отметить «Срочно».

### Кейс F2. Исправить ошибку в «Новой»

1. Открыть заказ со статусом «Новая».
2. Поправить позиции / примечание для курьера / файлы макета в блок точки.
3. Когда производство переведёт дальше — правка полей закроется.

### Кейс F3. Проблемный макет

1. Комментарии → текст + ☑ «Проблемный макет».
2. Уйдёт уведомление; в Telegram на карточке заказа появится флаг.

### Кейс F4. Создать задачу дизайнеру

1. Задачи → новая → назначить дизайнера, привязать заказ.
2. Следить во вкладке «Мои» / «Поставленные».

### Кейс F5. Чужой заказ

Точка А не увидит заказ точки Б — даже по прямой ссылке.
