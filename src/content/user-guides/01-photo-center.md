# Фотоцентр (точка) — руководство

Вы принимаете заказы на **своей точке** и видите только их.

**Меню:** Главная · Заказы · Новый заказ · Задачи · Справка

**Нет в меню:** Очередь, Клиенты (весь справочник), Отчёты, Каталог, Админка.

---

## Ваши ограничения

| Тема | Правило |
|------|---------|
| Заказы | Только `client_id` вашей точки |
| Статусы | **Не двигаете** ←/→ |
| Правка полей | Только свои заказы в статусе **«Новая»** (+ указать причину) |
| Цена после создания | Не меняете |
| Отмена / удаление | Нет, пока админ не выдаст флаг |
| Отчёты | **Никогда** |
| Файлы | Загрузка в блок **точки**; блок дизайнера — просмотр/скачивание своих заказов |
| Каталог | Только выбор позиций при создании заказа (чтение), без админки цен |

---

## Главная

Сводка по **вашим** заказам: статусы, срочные, последние. KPI с деньгами компании **нет** (отчёты закрыты).

**Пример:** видите, сколько ваших заказов ещё в «Новая» и что уже «Готов к выдаче».

---

## Заказы

### Список

1. Поиск по номеру.
2. Фильтр статусов и дат.
3. Раскрыть ▶ — состав.
4. Открыть карточку по клику.

Чужую точку **не увидите** — даже по прямой ссылке.

### Карточка заказа — что можно

| Действие | Можно? | Когда |
|----------|--------|-------|
| Смотреть состав, суммы, статусы | Да | Всегда свои |
| Править позиции / поля | Да | Только статус **«Новая»** + причина |
| Править после «Принят» и далее | **Нет** | Свяжитесь с производством |
| Статусы ←/→ | **Нет** | — |
| Комментарии + ☑ проблемный макет | Да | Свои заказы |
| «Для курьера» (куда везти) | Да (запись) | Пока заказ доступен |
| Файлы блока точки | Загрузка / скачивание | Свои |
| Файлы блока дизайнера | Обычно скачивание | Свои |
| Отмена | Только с флагом от админа | + причина |
| Soft-delete | Только с флагом | + пароль + комментарий |
| Аудит цен | Нет | — |
| ТТН | Нет | — |

**Пример:** опечатка в количестве — пока «Новая», правите сами; после «Принят» — пишете комментарий производству.

## Новый заказ

1. Клиент = **ваша точка** (сменить нельзя).
2. Каталог: категория → подкатегория → товар → количество. Цена подставится **с сервера**.
3. Или ☑ «Ручная позиция» — своё название и цена.
4. При необходимости «Срочно» и текст «Для курьера».
5. Сохранить → номер `DK-ГГММДД-N`.

**Нельзя:** подставить свою цену вместо каталожной у позиции из каталога (сервер всё равно возьмёт цену из прайса).

**Пример:** визитки из каталога 12.50 — в заказ уйдёт 12.50, даже если в форме пытались ввести другое.

## Задачи

| Вкладка | Смысл |
|---------|--------|
| Мои | Назначены вам |
| Поставленные | Создали вы |
| Все | Мои ∪ поставленные |

Можно создать задачу дизайнеру/производству и привязать заказ.

**Пример:** «Нужен макет визиток к DK-260902-1» → назначить дизайнера.

## Кейсы

### F1. Заказ из каталога
Новый заказ → выбрать позиции → сохранить → при необходимости загрузить макет в блок точки.

### F2. Исправление в «Новой»
Карточка → правка → указать причину → сохранить.

### F3. Проблемный макет
Комментарии → текст + ☑ «Проблемный макет» → уйдёт уведомление.

### F4. Чужой заказ
Точка Б ваш заказ не видит; вы не видите точку Б.
