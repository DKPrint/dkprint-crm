# Производство — руководство

Вы ведёте заказы по статусам, ТТН и очередь цеха. Видите **все** заказы (кроме soft-deleted по умолчанию).

**Меню:** Главная · Заказы · Новый заказ · Очередь · Задачи · Клиенты · Справка · Отчёты (только если админ включил флаг)

**Нет:** Каталог, Админка пользователей/SLA (настройка).

---

## Ваши ограничения

| Тема | Правило |
|------|---------|
| Правка полей / состава | Только заказы с `source=production` (созданные производством) |
| Заказы точек | Статусы, комментарии, ТТН, «для курьера», догрузка файлов точки, отмена/удаление — **без** правки состава как у «своих» |
| Статусы | ←/→ до «Готов к выдаче»; дальше курьер/админ |
| «Перейти в…» | Нет (только админ) |
| Цена после создания | Только с флагом `can_edit_price` |
| Отчёты | Только с флагом `can_access_reports` |
| Каталог цен | Нет (чтение при создании заказа — да) |

Админ может **снять** у вас отмену/удаление через deny-флаги.

---

## Главная

KPI месяца — **если** есть доступ к отчётам. Иначе: статусы, срочные, SLA, очередь, задачи, последние заказы.

---

## Заказы

### Список

Поиск, статусы, даты, раскрытие состава ▶, **ТТН**, срочность.

### Карточка — что можно

| Действие | Заказ точки (`source=photo_center`) | Свой (`source=production`) |
|----------|-------------------------------------|----------------------------|
| Смотреть всё | Да | Да |
| Править состав / поля | **Нет** | Да (если не cancelled/deleted) |
| Менять цену после создания | Нет / только с флагом | С флагом или нет |
| ←/→ статусы | Да (до ready) | Да |
| Комментарии, проблемный макет | Да | Да |
| «Для курьера» запись | Да | Да |
| Файлы блока точки | Догрузка | Да |
| Файлы блока дизайнера | Обычно нет загрузки | Смотреть по правилам |
| ТТН | Да | Да |
| Отмена (причина) | Да* | Да* |
| Soft-delete (пароль + comment) | Да* | Да* |
| Аудит | Да | Да |
| «Перейти в…» | Нет | Нет |

\* Если админ не снял право deny.

**Пример:** точка ошиблась в qty, заказ уже «Принят» — состав сами не правите; комментарий или эскалация админу. Свой производственный заказ — правите до отмены/удаления.

**Отмена ≠ удаление:** отмена — статус; удаление — скрытие (свой пароль).

---

## Новый заказ

1. Выберите клиента (точка или внешний).
2. Каталог или ручная позиция.
3. Сохранить — `source=production`, дальше можете править поля.

**Пример:** заказ для внешнего юрлица без логина точки.

---

## Очередь

Статусы «Принят» … «Готов к выдаче». ←/→ в строке, раскрытие состава и «макет: есть/нет», автообновление.

**Пример:** утром разобрать срочные и без макета.

---

## Задачи

Мои / Поставленные / Все (только ваши ∪ поставленные). Создание, смена статуса, привязка к заказу.

---

## Клиенты

Список точек и внешних. Карточка + история заказов. Soft-delete клиентов — **только админ**.

---

## Отчёты (если флаг)

Период, KPI, воронка, клиенты, категории, SLA, ТТН, экспорт. Отменённые и удалённые вне KPI.

## Кейсы

### P1. Принять заказ точки
Очередь / Заказы → «Новая» → → «Принят» → дальше по цепочке.

### P2. ТТН
В списке отметить галочку ТТН.

### P3. Отмена
Карточка → Отменить → причина.

### P4. Soft-delete
Удалить → свой пароль + комментарий.
