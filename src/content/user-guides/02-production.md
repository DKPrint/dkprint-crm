# Производство — руководство

## Кто вы

Ведёте заказы по статусам, ТТН, очередь цеха. Видите **все** заказы.

## Меню

Главная · Заказы · Новый заказ · Очередь · Задачи · Клиенты · Отчёты (только если админ включил флаг)

## Ограничения

- Поля заказа (состав, цены и т.п.) правите **только** у заказов, созданных производством (`source=production`).
- Заказы точек: можно статусы, комментарии, ТТН, «для курьера», догрузка файлов точки, отмена/удаление — **но не правка состава как у «своих»**.
- Статусы ←/→ до «Готов к выдаче»; дальше — курьер/админ.
- Нет «Перейти в…» (только админ).
- Нет админки и каталога (цены — через админа).
- Отчёты — только с флагом «Доступ к отчётам».
- Смена цены после создания — только с флагом «Редактирование цены» (или админ).

## Кейсы

### Кейс P1. Принять заказ с точки

1. Очередь или Заказы → заказ в «Новая».
2. → «Принят» → дальше по цепочке.
3. Раскрыть строку в очереди — состав и «макет: есть/нет».

### Кейс P2. Свой заказ производства

1. Новый заказ → выбрать клиента (точка или внешний).
2. Позиции из каталога / ручные.
3. Пока заказ живой — можете править поля (в рамках правил).

### Кейс P3. ТТН

1. В списке заказов — галочка ТТН (только production/admin).
2. В отчётах смотрится % ТТН (если есть доступ к отчётам).

### Кейс P4. Отмена

1. Карточка → Отменить → указать причину.
2. Заказ уйдёт из KPI; SLA остановится.

### Кейс P5. Soft-delete

1. Удалить → свой пароль + комментарий.
2. Заказ скрыт из рабочих списков (не путать с «Отменён»).
