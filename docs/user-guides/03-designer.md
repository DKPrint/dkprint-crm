# Дизайнер — руководство

## Кто вы

Работаете с макетами и статусами в цехе. Видите **все** заказы. **Не создаёте** заказы.

## Меню

Главная · Заказы · Очередь · Задачи · Клиенты · Отчёты (только с флагом)

## Ограничения

- Нет «Новый заказ».
- Нет правки полей заказа (состав/цены).
- **Никогда** нет отмены и soft-delete (даже если в админке ошибочно поставили флаг).
- Нет просмотра аудита цен.
- Файлы: загружаете в блок **дизайнера**; блок точки — скачивание по правам.
- Статусы ←/→ до «Готов к выдаче»; не ведёте курьерские этапы.
- Нет каталога/админки.

---

## Кейсы

### Кейс D1. Взять в работу

1. Очередь → заказ «Принят» → → «У дизайнера».
2. Загрузить файлы в блок дизайнера.
3. Комментарий + при необходимости ☑ проблемный макет.

### Кейс D2. Передать на производство

1. ←/→ до «На производстве» / дальше по процессу.
2. Нельзя отменить заказ — пишете комментарий, производство/админ решают.

### Кейс D3. Задача

1. Задачи → «Мои» — что назначено вам.
2. Меняете статус задачи: open → in_progress → done.
